GTU Materials
============

1. Keep index.html, style.css, script.js and the materials folder together.
2. Open index.html using VS Code Live Server to test.
3. Each subject card expands to show its individual original PDF files.
4. "Open PDF" opens that exact PDF in a new browser tab. The download icon downloads that file.
5. To add future notes, place PDFs in materials/WAD or materials/CN. Then add the exact file name to the matching array in script.js.
6. Deploy the complete folder to GitHub/Vercel. Do not upload only the HTML/JS/CSS files; the materials folder must also be included.

The empty PM chapter PDFs from the supplied ZIP were skipped because they contain 0 bytes. The available PM Catchment PDF is included.
